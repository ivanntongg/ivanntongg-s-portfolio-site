The Hip Hing Project Procedure Portal (PPP) 2.0 is a digital transformation
project designed to replace the outdated, inconsistent PPP 1.0. The goal was to
digitize workflows, centralize procedures, and reduce human error through
automation, structured document management, and improved collaboration.

## Initial challenge

PPP 1.0 was manual, inconsistent and time-consuming, leading to errors and
inefficiency.

- The workflow was heavily manual, relying on scattered Excel sheets.
- Documents were stored in inconsistent formats: free text, Excel, PDF templates.
- No automation, no central database, poor collaboration.
- Searching and retrieving files was inefficient and inconsistent.

## Design process

As the UI/UX Designer, I worked closely with clients and developers to:

- Understand the workflows of Admins, Approvers, Endorsers and Administrators.
- Map out the system architecture and user journeys.
- Create wireframes, prototypes and high-fidelity UI mockups.
- Build a scalable design system from scratch, ensuring consistency across pages
  and modules.

## Key features

### Walkthrough tutorial

- Interactive tutorial guides users through complex workflows.
- Ensures consistent usage of the system without external training.

### Creating a procedure

- Predefined templates ensure all documents follow a uniform structure.
- Reduces errors from free-text input or inconsistent formatting.
- Streamlines compliance and internal audits.

### Approval flow

- Multi-step approval ensures accountability at each stage.
- Automated routing minimises delays caused by manual handling.
- A built-in comment loop improves collaboration.

<Figure src={img04} alt="Reusable component set from the design system." caption="Reusable components designed to maintain consistency." />

### Version tracking

- Stores every update, enabling teams to view a document's evolution.
- Every edit is recorded with timestamp, editor name and change summary.

## Outcome

PPP 2.0 transformed a previously manual and fragmented process into a fully
digitized, centralized and automated platform.
