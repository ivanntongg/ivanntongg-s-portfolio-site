The AsDayOne design system establishes a consistent set of guidelines, reusable
components and scalable patterns. It was created to streamline product
development, improve collaboration, and ensure a unified user experience across
platforms.

## Initial challenge

When I joined, the team lacked a design system. Every designer and developer had
their own way of building UI. This led to:

- Inconsistent styles across products.
- Repeated work on basic components.
- Misalignment between design and development.
- Longer timelines to ship new features.

The challenge was clear: create a scalable, flexible and accessible design system
that worked across multiple projects while establishing consistency.

<Figure src={img02} alt="Unorganised design file with inconsistent styling." caption="The starting point: an unorganised file with inconsistent styling and repeated components." />

## Building the system

I started by auditing existing designs to identify patterns, redundancies and
gaps. From there I structured AsDayOne around three principles: scalability,
accessibility and consistency.

**Core components.** Foundational elements (buttons, inputs, navigation, modals)
that adapt to different contexts while staying on-brand.

**Design tokens.** Rules for color, typography, spacing and shadows to ensure a
unified visual identity.

**Reusable libraries.** Figma libraries with each component's behavior documented
to streamline adoption.

Collaboration was essential. I worked closely with developers to align on
feasibility and with designers to ensure usability across workflows.

## Interaction and visual design

To make the system feel dynamic rather than static, I built an interactive guide
demonstrating component behaviors, transitions and micro-interactions. Each
component was documented with usage guidelines, so both designers and developers
could apply them confidently.

## Impact

What started as a fragmented workflow became a structured, scalable system that
continues to support the company's growing product ecosystem.
